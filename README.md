# Flutter Practical Work — Figma Layouts

Four Flutter screens based on the supplied Figma references:
- Secrets of Atlantis
- Meditate
- 3D Design Basic / Course Details
- My E-Wallet

The supplied reference images are stored in `assets/images/` and used by the corresponding screens.

## Run on iPhone Simulator

```bash
flutter pub get
flutter devices
flutter run -d "iPhone 18 Pro"
```

In VS Code, select `iPhone 18 Pro (ios simulator)` in the device selector and press F5.
